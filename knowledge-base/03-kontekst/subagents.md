## Простыми словами

**Субагент** — отдельный помощник с своим «окном памяти». Главный Agent отдаёт ему подзадачу и получает краткий ответ.

## Встроенные (не настраивать)

| Субагент | Зачем |
|----------|-------|
| **Explore** | Искать по проекту |
| **Bash** | Команды в терминале |
| **Browser** | Работа с веб-страницей |

## Свои субагенты

Файл `.cursor/agents/имя.md` или `~/.cursor/agents/имя.md`:

```markdown
---
name: moy-pomoshchnik
description: Проверяет текст на ошибки. Use proactively.
readonly: true
---
```

Для совместимости Cursor читает также `.claude/agents/` и `.codex/agents/` (проект) и `~/.claude/agents/`, `~/.codex/agents/` (пользователь). При конфликте имён приоритет у `.cursor/`.

## Foreground и background

| Режим | Поведение | Когда |
|-------|-----------|-------|
| **Foreground** | Ждёт завершения и сразу возвращает результат | Нужен ответ для следующего шага |
| **Background** (`is_background: true`) | Возвращается сразу, субагент работает сам | Долгие задачи, параллельные потоки |

Background-субагенты пишут свой вывод в `~/.cursor/subagents/` — родитель может подсмотреть прогресс там.

## Модель субагента

Поле `model` в frontmatter: `inherit` (модель родителя, default) или конкретный ID модели. Параметры модели — в квадратных скобках, пары `id=value` через запятую:

```markdown
---
model: claude-opus-5[effort=high,context=300k]
---
```

Примеры: `composer-2.5[fast=false]` — стандартный вариант вместо fast; `claude-opus-5[effort=high]` — высокое reasoning effort. Доступные параметры зависят от модели.

## Cloud subagents

Из локальной сессии можно отдать задачу облачному субагенту — он работает на своей VM и ветке, а ваш workspace остаётся чистым:

- `/in-cloud` — следующая задача уйдёт облачному субагенту
- `/babysit` — облачный агент доводит pull request до merge

Запускаются из Agents Window; MCP-серверы у них — из командной конфигурации на cursor.com/agents, не из локальной сессии.

## Resume субагента

Каждый запуск субагента возвращает **agent ID**. По нему субагента можно продолжить с сохранённым контекстом:

```text
> Resume agent abc123 и разбери оставшиеся падения тестов
```

## Вложенность

С Cursor 2.5 субагент может запускать дочерних субагентов, но максимум на 2 уровня: главный Agent и его прямые субагенты запускать могут, а субагент, запущенный другим субагентом, — уже нет.

## Когда subagent, когда skill

| Subagent | Skill |
|----------|-------|
| Долгое исследование | Одна быстрая операция |
| Нужна изоляция контекста | Не нужен отдельный контекст |
| Параллельные задачи | Один шаг |

## Пошагово

1. Создайте `.cursor/agents/verifier.md`
2. Перезапустите Cursor (если глобально — после копирования в `~/.cursor/agents/`)
3. Попросите Agent: «используй verifier для проверки»
