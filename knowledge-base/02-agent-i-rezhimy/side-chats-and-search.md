# Side chats и поиск по чатам

## Простыми словами

**Side chat** — отдельный дочерний разговор рядом с основным чатом: история родителя доступна модели как скрытый контекст, а основная ветка не засоряется. **Поиск по чатам** находит прошлые разговоры и нужные места внутри длинных транскриптов.

## Как открыть side chat

1. Введите `/side` в поле чата — откроется пустой side chat; допишите вопрос после команды, чтобы отправить его сразу
2. Выделите текст или diff в чате → **Ask in Side Chat** в меню выделения
3. Шорткат с текущим выделением транскрипта: **Shift+Cmd+S** (Mac) / **Shift+Ctrl+S** (Windows/Linux)

По умолчанию side chats сфокусированы на чтении, поиске и ответах — основной агент продолжает работать без перерыва.

## Свойства side chat

- История родителя — скрытый референс-контекст для модели; в транскрипте side chat она не отображается
- Это полноценный durable-разговор: follow-up сообщения остаются в side chat и не попадают в родителя
- Вернуть находки в основной чат — @-mention side chat в главной ветке
- Вложенность не поддерживается: side chat не может порождать собственные side chats
- Это не fork: fork копирует весь разговор целиком, а side chat только подкармливает модель историей родителя
- Пока local-only: для Cloud Agents недоступно
- Кнопка **X** архивирует side chat — разговор не удаляется

## Поиск по чатам

По всем прошлым разговорам:

1. Откройте Agents Window
2. **Cmd+K** (Mac) / **Ctrl+K** (Windows/Linux) — палитра команд
3. Ищите по транскриптам — локальный индекс масштабируется до тысяч разговоров

Внутри открытого разговора: **Cmd+F** / **Ctrl+F** и переход между совпадениями по счётчику.

## Частые ошибки

- Пытаться открыть side chat внутри side chat — не поддерживается, начинайте из родительского разговора
- Ждать side chats у Cloud Agents — пока они работают только локально
