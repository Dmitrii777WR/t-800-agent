# Agents Window — окно агентов

## Простыми словами

Agents Window — место, где вы открываете и ведёте чаты с Agent, переключаете задачи и работаете с несколькими агентными сессиями.

## Когда вам это нужно

- Создать новый чат Agent
- Вернуться к прошлой задаче
- Открыть canvas или вкладку агента
- Разделить разные задачи по разным сессиям

## Как открыть

- `Cmd+Shift+P` → **Open Agents Window** — из редактора
- `Cmd+Shift+P` → **Open IDE** — назад в классический редактор
- Внутри окна: `Cmd+P` — найти файл, `Cmd+Shift+F` — искать по всем файлам (не выходя из окна)

## Что умеет окно (из официальной docs)

- **Multi-workspace** — агенты по всем вашим проектам из одного места
- **Новый вид diffs** — ревью и коммит изменений, управление PR без выхода из Cursor
- **Параллельные агенты** — много агентов в облаке одновременно (и с телефона, веба, Slack, GitHub, Linear)
- **Handoff local ↔ cloud** — забрать облачного агента локально для итерации и вернуть обратно
- **Cloud subagents** — `/in-cloud` отдать задачу облачному субагенту, `/babysit` довести PR до merge
- **Worktrees** — агенты в изолированных git-checkout'ах: у каждой задачи свои файлы

Окно доступно всем с Cursor 3 (релиз 2 апреля 2026); первые две недели после запуска Enterprise-админы могли управлять выкаткой через Team settings.

## Pickers: где запускать агента

- Под полем ввода агента — выпадающий список среды: локально или **Cloud** (облачная VM с окружением репозитория)
- **Multi-workspace** окна — работа сразу по нескольким проектам из одного места
- Облачные агенты умеют **multi-repo окружения**: одна задача на связанные frontend/backend/infrastructure репозитории, агент открывает PR в затронутых репо

## Side chats (боковые чаты)

Side chat — дочерний чат рядом с основным: история родителя подмешана как скрытый контекст, а своя переписка видна отдельно. Удобно для побочного вопроса, не засоряя основной тред.

- Открыть: команда `/side` в поле ввода; выделить текст или diff → **Ask in Side Chat**; шорткат `Shift+Cmd+S` (Mac) / `Shift+Ctrl+S` (Windows/Linux)
- Вернуть находки в основной чат: @-упомянуть side chat в родительском треде
- Это не fork: side chat не копирует переписку родителя, а даёт её модели как фон
- Вложенных side chats нет; пока работают только локально (не для Cloud Agents); закрытие крестиком = архив, не удаление

## Поиск по разговорам

- По всем прошлым чатам: в Agents Window нажать `Cmd+K` (Mac) / `Ctrl+K` (Windows/Linux) — локальный индекс масштабируется до тысяч бесед
- Внутри открытого чата: `Cmd+F` / `Ctrl+F` — переход по совпадениям со счётчиком

## Правило для новичка

Одна большая задача — один отдельный чат. Не смешивайте «объясни проект», «сделай форму» и «запусти деплой» в одной длинной беседе.

## Пошагово

1. Откройте Agents Window
2. Создайте новый агентный чат для новой задачи
3. Назовите задачу понятным первым сообщением
4. Если тема изменилась — лучше новый чат
5. Старые чаты используйте как историю, но не как бесконечную память

## Частые ошибки

- Продолжать новую тему в старом чате
- Терять контекст, потому что не указали файлы через `@`
- Ожидать, что Agent помнит все прошлые проекты
