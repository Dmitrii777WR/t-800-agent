# Cursor Agent

Agent — это помощник Cursor, который может самостоятельно выполнять сложные задачи программирования, запускать команды в терминале и редактировать код. Доступен на боковой панели по Cmd+I.

Узнайте больше о [том, как работают агенты](https://cursor.com/learn/agents.md), и ускорьте разработку.

## Как работает Agent

Agent построен на трёх компонентах:

1. **Instructions**: системная инструкция и [rules](https://cursor.com/docs/rules.md), которые направляют поведение Agent
2. **Tools**: редактирование файлов, поиск по кодовой базе, выполнение команд в терминале и другое
3. **Model**: модель, которую вы выбираете для задачи

Agent в Cursor координирует работу этих компонентов для каждой поддерживаемой нами модели, настраивая инструкцию и инструменты специально под каждую передовую модель. По мере появления новых моделей вы можете сосредоточиться на разработке программного обеспечения, а Cursor возьмёт на себя оптимизации под конкретные модели.

## Инструменты

Инструменты — это базовые компоненты Agent. Они используются для поиска по вашей кодовой базе и в интернете, чтобы находить релевантную информацию, вносить изменения в файлы, запускать терминальные команды и многое другое.

Чтобы понять, как под капотом работает вызов инструментов, см. раздел [основы вызова инструментов](https://cursor.com/learn/tool-calling.md).

Количество вызовов инструментов, которые Agent может сделать во время выполнения задачи, не ограничено.

### Search files and folders

Ищите файлы по имени, просматривайте структуры каталогов и находите точные ключевые слова или шаблоны внутри файлов.

### Web

Генерируйте поисковые запросы и выполняйте поиск в интернете.

### Fetch Rules

Получайте конкретные [правила](https://cursor.com/docs/rules.md) по типу и описанию.

### Read files

Интеллектуально считывайте содержимое файла. Также поддерживаются файлы изображений (.png, .jpg, .gif, .webp, .svg), которые включаются в контекст диалога для анализа моделями с поддержкой зрения.

### Edit files

Предлагайте изменения в файлах и применяйте их автоматически.

### Run shell commands

Выполняйте терминальные команды и отслеживайте вывод. По умолчанию Cursor использует первый доступный профиль терминала.

Чтобы задать предпочитаемый профиль терминала:

1. Откройте Command Palette (`Cmd/Ctrl+Shift+P`)
2. Найдите "Terminal: Select Default Profile"
3. Выберите нужный профиль

### Browser

Управляйте браузером, чтобы делать скриншоты, тестировать приложения и проверять визуальные изменения. Agent может переходить по страницам, взаимодействовать с элементами и фиксировать текущее состояние для анализа. Подробности см. в [документации Browser](https://cursor.com/docs/agent/tools/browser.md).

### Image generation

Генерируйте изображения по текстовым описаниям или референсным изображениям. Полезно для создания UI-макетов, продуктовых ассетов и визуализации архитектурных диаграмм. По умолчанию изображения сохраняются в папку `assets/` вашего проекта и отображаются прямо в чате.

### Ask questions

Задавайте уточняющие вопросы во время выполнения задачи. Пока Agent ждёт вашего ответа, он продолжает читать файлы, вносить изменения или запускать команды. Ваш ответ учитывается сразу после получения.

## Checkpoints

Контрольные точки сохраняют снимки вашей кодовой базы во время сеанса с Agent. Agent автоматически создаёт их перед внесением существенных изменений, фиксируя состояние всех изменённых файлов.

Если Agent свернёт не туда, нажмите на любую контрольную точку в ленте чата, чтобы просмотреть файлы в состоянии на тот момент, затем нажмите «Восстановить», чтобы вернуть все файлы к этому состоянию. Вы также можете восстановить из кнопки `Restore Checkpoint` в предыдущих запросах или через кнопку «+» при наведении курсора на сообщение.

Контрольные точки полезны для исследовательской работы, сложного рефакторинга и итеративной разработки, когда вам нужны безопасные точки отката.

Контрольные точки хранятся локально и отдельно от Git. Используйте их только для
отмены изменений Agent; для постоянного контроля версий используйте Git.

## Очередь сообщений

Ставьте последующие сообщения в очередь, пока Agent выполняет текущую задачу. Инструкции будут автоматически выполнены, как только дойдёт их очередь.

[Media](/docs-static/images/agent/planning/agent-queue.mp4)

### Использование очереди

1. Пока Agent работает, введите следующую инструкцию
2. Нажмите Enter, чтобы добавить её в очередь
3. Сообщения отображаются ниже активной задачи в порядке очереди
4. Перетащите сообщения в очереди, чтобы при необходимости изменить их порядок
5. После завершения текущей задачи Agent обработает их по очереди

### Горячие клавиши

Пока Agent выполняет задачу:

- Нажмите Enter, чтобы поставить сообщение в очередь (оно будет ждать, пока Agent завершит текущую задачу)
- Нажмите Cmd+Enter, чтобы отправить сообщение сразу, минуя очередь

### Мгновенная отправка сообщений

Когда вы используете Cmd+Enter для мгновенной отправки, ваше сообщение добавляется к последнему пользовательскому сообщению в чате и обрабатывается сразу, без ожидания в очереди.

- Ваше сообщение прикрепляется к результатам работы инструментов и отправляется сразу
- Это обеспечивает более быстрый отклик для срочных последующих сообщений
- Используйте это, когда нужно прервать или перенаправить текущую работу Агента
