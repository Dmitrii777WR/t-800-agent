# Автодополнение Tab

Tab — это ИИ-автодополнение в Cursor. Оно предлагает код по мере ввода с учетом недавних правок, окружающего контекста и ошибок линтера.

## Как принять или отклонить подсказки?

- **Принять подсказку целиком**: Нажмите Tab
- **Отклонить**: Нажмите Escape или просто продолжайте печатать
- **Принимать по слову**:
  - **Mac**: Нажмите Cmd + Arrow Right
  - **Windows/Linux**: Нажмите Ctrl + Arrow Right

Подсказки отображаются серым текстом перед курсором.

## Может ли Tab редактировать несколько строк одновременно?

Да. Tab может изменять несколько строк, добавлять недостающие операторы import и предлагать согласованные правки в связанном коде.

## Что такое jump-in-file?

После того как вы примете подсказку Tab, снова нажмите Tab. Tab предугадывает следующее место редактирования и переносит вас туда. Это избавляет от необходимости прокручивать документ или переходить вручную.

## Может ли Tab предлагать правки в других файлах?

Да. Tab предугадывает правки в других файлах, когда изменения в одном файле требуют обновлений в другом. Когда доступен переход в другой файл, в нижней части Редактора появляется окно портала.

## Как включить или отключить Tab?

Нажмите на индикатор состояния **Tab** в правом нижнем углу Cursor. В открывшемся меню можно:

- **Приостановить**: Временно отключить Tab на выбранное время
- **Отключить глобально**: Отключить Tab для всех файлов
- **Отключить для определённых расширений**: Отключить Tab для определённых типов файлов (например, markdown или JSON)

Вы также можете настроить параметры Tab в **Cursor Settings** > **Tab**.

## Можно ли изменить сочетание клавиш для Tab?

Да. Найдите `Accept Cursor Tab Suggestions` в настройках **Keyboard Shortcuts**, чтобы переназначить это сочетание.
