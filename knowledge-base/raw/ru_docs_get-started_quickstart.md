# Быстрый старт

Это руководство поможет вам перейти от установки к первому полезному изменению в Cursor. Вы войдёте в систему, попросите Cursor объяснить вашу кодовую базу, внесёте небольшое изменение и проверите результат.

### Установите Cursor и войдите в систему

Скачайте Cursor. Откройте приложение и войдите в систему. Затем выберите папку и начните с небольшой задачи.

### macOS

- macOS 12 (Monterey) и новее
- Нативный установщик (.dmg)
- Поддержка Apple Silicon и Intel

### Windows

- Windows 10 и новее
- Нативный установщик (.exe)

### Linux

**Debian/Ubuntu (рекомендуется)**

```bash
# Add Cursor's GPG key
curl -fsSL https://downloads.cursor.com/keys/anysphere.asc | gpg --dearmor | sudo tee /etc/apt/keyrings/cursor.gpg > /dev/null

# Add the Cursor repository
echo "deb [arch=amd64,arm64 signed-by=/etc/apt/keyrings/cursor.gpg] https://downloads.cursor.com/aptrepo stable main" | sudo tee /etc/apt/sources.list.d/cursor.list > /dev/null

# Update and install
sudo apt update
sudo apt install cursor
```

**RHEL/Fedora**

```bash
# Add Cursor's repository
sudo tee /etc/yum.repos.d/cursor.repo << 'EOF'
[cursor]
name=Cursor
baseurl=https://downloads.cursor.com/yumrepo
enabled=1
gpgcheck=1
gpgkey=https://downloads.cursor.com/keys/anysphere.asc
EOF

# Install Cursor
sudo dnf install cursor
```

**AppImage (портативная версия)**

Скачайте файл `.AppImage` с [cursor.com/downloads](https://cursor.com/downloads), затем:

```bash
chmod +x Cursor-*.AppImage
./Cursor-*.AppImage
```

Пакеты apt и yum предпочтительнее, чем AppImage. Они предоставляют значки приложений, автоматические обновления и инструменты CLI.

### Попросите Cursor объяснить вашу кодовую базу

После того как вы выберете папку, откройте Agent с помощью Cmd I. Попросите Cursor объяснить кодовую базу и указать, какие основные части стоит изучить в первую очередь.

Объясни эту кодовую базу. Укажи основные точки входа, ключевые модули и всё, что мне стоит прочитать перед внесением изменений.

Cursor выполнит поиск по вашему репозиторию, прочитает релевантные файлы и кратко объяснит, как устроен проект. Это один из самых быстрых способов сориентироваться в незнакомой кодовой базе.

Нужен более подробный разбор? См. [Изучение вашей кодовой базы](https://cursor.com/learn/understanding-your-codebase.md).

### Внесите одно небольшое изменение

Когда вы поймёте проект, попросите Cursor предложить несколько безопасных улучшений. Выберите одно и попросите его внести это изменение.

Предложи три небольших и безопасных улучшения в этой кодовой базе. Объясни компромиссы и подожди, пока я выберу одно.

Хорошие первые задачи — с низким риском, например улучшение текста интерфейса или исправление небольших проблем UI.

Если вы уже знаете, что хотите изменить, попросите об этом напрямую и опишите нужный результат.

### Просмотрите diff и проверьте результат

Теперь вы можете наблюдать за работой Cursor. В diff показаны изменения, внесённые агентом.

Когда всё будет готово, просмотрите diff и попросите Cursor запустить проверки, которые уже используются в вашем проекте. Это могут быть тесты, проверка типов, линтинг или локальная сборка.

Нужен более надёжный процесс ревью? См. [Ревью и тестирование кода](https://cursor.com/learn/reviewing-testing.md).

### Используйте Plan Mode для более крупных изменений

Теперь, когда вы знаете основы, используйте Plan Mode для более крупных изменений. Этот режим хорошо подходит, когда задача охватывает несколько файлов, требует исследования или согласования перед написанием кода.

Нажмите Shift+Tab в поле ввода агента, чтобы переключить **Plan Mode**. Вместо того чтобы сразу писать код, Cursor будет:

1. Исследовать вашу кодовую базу, чтобы найти релевантные файлы
2. Задавать уточняющие вопросы о ваших требованиях
3. Создавать подробный план реализации
4. Ждать вашего одобрения перед началом работы

Более подробный разбор см. в разделе [Создание новых функций](https://cursor.com/learn/creating-features.md).
