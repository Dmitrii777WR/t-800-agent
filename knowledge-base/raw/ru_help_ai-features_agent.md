# режим Agent

Agent — это ИИ-помощник Cursor. Он ищет в вашей кодовой базе, редактирует несколько файлов, выполняет команды в терминале и самостоятельно исправляет ошибки.

## Что может режим Agent?

Agent может с нуля создавать новые функции, рефакторить существующий код, исправлять ошибки, писать тесты и выполнять команды оболочки. Опишите задачу простым языком, и он сам определит, какие файлы нужно прочитать, какие изменения внести и как проверить результат.

## Как начать пользоваться Agent?

1. Откройте панель Agent:
   - **Mac**: Нажмите Cmd + I
   - **Windows/Linux**: Нажмите Ctrl + I
2. Введите запрос. Чётко опишите, что вам нужно. Например: "Добавь форму входа на главную страницу с полями email и пароля."
3. Нажмите Return. Agent начнёт анализировать вашу кодовую базу и вносить изменения.
4. Следите за тем, как правки появляются в представлении diff по мере работы.

Вы также можете запускать агентов из браузера на [cursor.com/agents](https://cursor.com/agents) с помощью Cloud Agents.

## Как прервать Agent?

Нажмите кнопку **Остановить**, чтобы прервать работу Agent в процессе выполнения задачи. Это позволит изменить направление или выбрать другой подход.

## Как провести ревью изменений Agent?

Правки Agent применяются по мере его работы. Просматривайте их в представлении diff и отклоняйте всё, что не хотите сохранять. Для ревью на уровне PR [Bugbot](https://cursor.com/help/ai-features/bugbot.md) может автоматически находить ошибки и проблемы безопасности.

## Как отменить изменения, внесённые Agent?

Наведите курсор на предыдущее сообщение и нажмите **Восстановить контрольную точку** в правом нижнем углу, чтобы откатить все изменения, которые Agent внес после этого.

## Может ли Agent делегировать задачи субагентам?

Да. Agent может запускать специализированных [субагентов](https://cursor.com/docs/subagents.md), чтобы параллельно выполнять поиск информации, команды оболочки или действия в браузере. Каждый субагент работает в собственном контекстном окне и возвращает результат в основной диалог. Вы также можете создавать пользовательских субагентов, добавляя markdown-файлы в `.cursor/agents/`.

## Может ли Agent генерировать изображения?

Да. Agent может создавать изображения по текстовым описаниям или изображениям-референсам. Это полезно для макетов интерфейса, графических материалов продукта или архитектурных диаграмм. Сгенерированные изображения сохраняются в проекте и отображаются прямо в чате.

## Можно ли поставить в очередь следующие сообщения, пока Agent работает?

Да. Отправьте следующую инструкцию, пока Agent занят. Ваше сообщение будет ждать в очереди и автоматически выполнится, когда текущая задача завершится. Сообщения в очереди можно перетаскивать, чтобы менять их порядок.

## Может ли Agent искать контекст в моих прошлых диалогах?

Да. Agent может использовать поиск по диалогам как инструмент. Когда Agent нужен контекст из того, что вы обсуждали раньше, он может сам выполнить поиск по вашим прошлым диалогам. Вам не нужно помнить, в каком чате это было.

## Какой режим выбрать?

| Режим     | Лучше всего подходит для                                      | Может редактировать файлы?           |
| --------- | ------------------------------------------------------------- | ------------------------------------ |
| **Agent** | Создания функций, рефакторинга, исправления ошибок            | Да                                   |
| **Ask**   | Понимания кода, изучения архитектуры                          | Нет (только чтение)                  |
| **Plan**  | Сложных функций, где вы хотите сначала провести ревью подхода | Да (после того как вы одобрите план) |
| **Debug** | Сложных ошибок, для которых нужны данные времени выполнения   | Да                                   |

Используйте Agent для большинства задач. Переключайтесь на Ask, когда хотите получить ответы без изменений. Используйте Plan для функций, затрагивающих несколько файлов, если хотите сначала провести ревью подхода. Используйте Debug для ошибок, которые трудно воспроизвести или понять.

## Как переключаться между режимами?

- Нажмите Shift + Tab, чтобы переключать режимы
- Нажмите на раскрывающийся список выбора режима в панели Agent

У каждого режима свой контекст, поэтому при переключении начинается новый контекст. Для лучших результатов при смене задачи начинайте новый чат.

## Правила действуют во всех режимах?

Да. Правила проекта, пользовательские правила и правила команды действуют в режимах Agent, Ask, Plan и Debug. Они добавляются в каждый диалог независимо от того, какой режим вы используете.
