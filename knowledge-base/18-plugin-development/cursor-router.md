# Cursor Router — автовыбор модели

## Простыми словами

**Cursor Router** — механизм внутри режима **Auto**: вы не выбираете модель сами, а классификатор анализирует каждый запрос и отправляет его подходящей модели — простые задачи быстрым и дешёвым, сложные самым способным. Сейчас доступен только на планах **Teams и Enterprise**.

## Режимы оптимизации

Откройте выбор модели → **Auto** → секция **Optimize For**:

| Режим | Что делает | Когда выбрать |
|-------|------------|---------------|
| **Cost** | Прежняя логика Auto: оптимизирует расход токенов, bundled-цена за миллион токенов независимо от модели | Хотите расходы на уровне прежнего Auto |
| **Balance** | Баланс интеллекта, скорости и стоимости; режим по умолчанию для новых пользователей | Повседневная работа |
| **Intelligence** | Самые способные модели для сложных задач, дешевле, чем гнать всё через одну frontier-модель | Сложная многошаговая работа — по help даёт примерно на 20–30% выше качество |

Balance и Intelligence расходуют лимиты быстрее, чем Cost: они оплачиваются по тарифу модели, которую выбрал Router, — в среднем примерно в 2 раза дороже Cost, максимум в 2–4 раза. Переключать режим можно в любой момент.

## Как Router решает

ML-классификатор запускается на каждый запрос агента и маршрутизирует его по типу и сложности задачи. Модель для запроса выбрать вручную нельзя — вы управляете только режимом оптимизации, а пул моделей со временем меняется.

## Пулы моделей

- Собственные модели Cursor (Grok 4.5, Composer) входят в пул **Cursor Models**; рядом работают другие frontier-модели от OpenAI, Anthropic и Google (third-party)
- Текущий пул маршрутизации Router: Composer 2.5 (варианты fast и standard), GPT-5.5, Claude Opus 5, Grok 4.5, Claude Fable 5
- **Grok 4.5 обязателен**: Router нужна мощная и экономичная модель в пуле, блокировка Grok 4.5 отключает Router
- На Teams/Enterprise запросы к third-party моделям (в том числе через Auto Balance/Intelligence) облагаются Cursor Token Rate — $0.25 за миллион токенов; Auto Cost и first-party модели от него освобождены

## Контроли администратора (Teams)

Настраивается в дашборде команды:

- **Enable Cursor Router** — вкл/выкл маршрутизацию; на Enterprise по умолчанию выключен, настраивается и по organization groups
- **Routing preferences** — какие режимы видят участники (можно отключить до 2)
- **Underlying model** — показывать или скрывать, какая модель ответила; по умолчанию скрыта, и это рекомендовано, чтобы результат оценивали по заслугам, а не по имени модели
- **Impose Auto** — **Soft** (Auto по умолчанию в новых чатах, переключиться можно) или **Hard** (выбор модели заблокирован на Auto)

Если модель заблокирована для команды, Router пропускает её и уходит в разрешённую альтернативу; блокировка слишком многих моделей снижает качество маршрутизации и может отключить Router.

## Для разработчиков (SDK)

В TypeScript и Python SDK Router доступен как модель `auto-smart` с параметром `optimize_for` (`cost`, `balanced`, `intelligence`).

## Частые ошибки

- Искать Router на личных планах — он только на Teams/Enterprise
- Блокировать Grok 4.5 в настройках команды — Router отключится
